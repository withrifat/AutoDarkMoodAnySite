## 🚀 **Installation**  

### 🔹 **_From Chrome Web Store_**  
1. Go to the [**Chrome Web Store**](https://chrome.google.com/webstore/detail/your-extension-id).  
2. Click **_Add to Chrome_** and confirm the installation.  
3. **Done! 🎉**  

### 🔹 **_Manual Installation (Developer Mode)_**  
1. **Download** or **clone** this repository.  
2. Open **Chrome** and go to `chrome://extensions/`.  
3. Enable **`Developer Mode`** (top right corner).  
4. Click **`Load unpacked`** and select the extension folder.  
5. **Enjoy Auto Dark Mode! 😍**  

---

## ⚙️ **How It Works**  
1. **_Detects your system's dark mode settings._**  
2. **_Applies CSS filters_** to convert websites to dark mode.  
3. **_Allows users to customize the experience._**
